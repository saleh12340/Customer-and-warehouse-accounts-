حول التطبيق وسياسة الخصوصية

بقالة العزي للمواد الغذائية - نظام Pro

تطبيق محاسبة متكامل لإدارة المبيعات والمشتريات والمخزون وديون العملاء والموردين باللغة العربية، مع طباعة حرارية (58مم / 80مم)، إنشاء فواتير PDF احترافية، ومشاركة الفواتير وكشوفات الحساب عبر واتساب.

سياسة الخصوصية والأمان

  • يعمل التطبيق بنسبة 100% دون اتصال بالإنترنت (Offline).
  • تُحفظ جميع الفواتير والأرصدة وحركات الحساب محلياً على جهازك داخل قاعدة بيانات SQLite/Room، وتُحفظ الصادرات والصور والنسخ الاحتياطية في مجلد Download/بقاله العزي.
  • لا يرسل التطبيق أي بيانات إلى خوادم خارجية أو أطراف ثالثة.
  • أذونات البلوتوث تُستخدم فقط للبحث والاتصال بالطابعة الحرارية المقترنة.
